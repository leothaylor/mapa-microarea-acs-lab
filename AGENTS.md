# Instruções para agentes — Rotina ACS LAB

Projeto público de demonstração de mapa territorial. **Nunca utilizar dados reais do My Maps/pacientes.** Nenhum backend, dados clínicos, login, token, coleta remota ou integração PEC.

**Antes de modificar qualquer código, leia integralmente** \`docs/PLANO_IMPLEMENTACAO_ASTRA.md\` (retire qualquer caractere invisível ao resolver o caminho; o arquivo chama-se \`PLANO_IMPLEMENTACAO_ASTRA.md\`), \`README.md\`, \`index.html\`, \`app.js\`, \`sw.js\`.

Foco da execução com recursos limitados: **P0 primeiro, P1 depois; P2 somente se houver margem. P3 fora de escopo.** Não reestruture o projeto em framework pesado. Preserve GitHub Pages (main/root), a identidade visual e a migração do localStorage \`rotina-acs-lab-map-v01\`. Testes objetivos e commit funcional. O usuário quer testar as mudanças no endereço GitHub Pages, sem depender de Codex para cada nova alteração.
