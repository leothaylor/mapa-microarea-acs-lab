# Instruções para agentes — Rotina ACS LAB

Projeto público de demonstração de mapa territorial. **Nunca utilizar dados reais do My Maps/pacientes.** Nenhum backend, cadastro clínico, login, token, coleta remota ou integração PEC.

**Antes de modificar código, leia:** `docs/PLANO_IMPLEMENTACAO_ASTRA.md`, `README.md`, `index.html`, `app.js` e `sw.js`.

Foco da execução com créditos limitados: **P0 primeiro, P1 depois; P2 somente se houver margem. P3 fora de escopo.** Não migrar para framework pesado. Preserve GitHub Pages (main/root), identidade visual e migração do localStorage `rotina-acs-lab-map-v01`. Implemente interações reais, teste e faça commits funcionais. O usuário testará as mudanças pelo GitHub Pages.
